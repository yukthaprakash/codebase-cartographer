Thank you for your interest in contributing to AI Codebase Cartographer!

How to contribute

- Bug reports: open an issue with steps to reproduce, expected behavior, and environment.
- Feature requests: open an issue describing the use case and suggested UX.
- Code contributions: fork the repo, create a branch, add tests if applicable, and open a PR. Keep changes small and focused.

Developer workflow

```bash
git clone https://github.com/yukthaprakash/codebase-cartographer.git
git checkout -b feat/your-feature
npm install
npm run compile
# run tests (if added in future)
```

Code style

- TypeScript for the extension host code.
- Keep changes minimal and add documentation for any new public behavior.

Thank you — maintainers will review PRs and respond with feedback.
